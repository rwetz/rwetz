### What I'm working on

**[Nexis](https://github.com/rwetz/Nexis)** ([nexisdev.org](https://nexisdev.org/)) — an open-source, AI-native terminal emulator with a built-in editor, file explorer, and multi-provider AI agents. Tauri 2 + Rust + React 19. It has grown into a small ecosystem:

| Repo | Stack | What it is |
| --- | --- | --- |
| [Nexis](https://github.com/rwetz/Nexis) | Rust · React 19 | The terminal itself — Tauri 2, integrated editor, file explorer, AI agents |
| [nexis-ml-rs](https://github.com/rwetz/nexis-ml-rs) | Rust | Python-free single-binary ML engine, GPU training via `wgpu`, ONNX export |
| [nexis-ml](https://github.com/rwetz/nexis-ml) | Python | The original engine — train small models on small data, stream live metrics |
| [nexis-benchmark](https://github.com/rwetz/nexis-benchmark) | TypeScript | Benchmarks local ONNX/GGUF models across inference backends — throughput, latency, memory |
| [nexis-dev-dashboard](https://github.com/rwetz/nexis-dev-dashboard) | Rust · React | Git status across every local repo at once, scanned in parallel with `git2` + `rayon` |
| [nexis-website](https://github.com/rwetz/nexis-website) | Next.js 16 | Marketing site — shadcn/ui, Tailwind v4, framer-motion |
| [nexis-wiki](https://github.com/rwetz/nexis-wiki) | Astro | Documentation, built with Starlight → [wiki.nexisdev.org](https://wiki.nexisdev.org) |
